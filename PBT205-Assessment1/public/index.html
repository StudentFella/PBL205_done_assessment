PBT205 Assessment 1

Three prototypes talking through RabbitMQ

Task 1: ChatJoin a room and chat with other users. Task 2: TradingSend orders and watch the latest traded price. Task 3: Contact tracingWatch people move around the board and query who has met who.

The GUIs are only one way in. Each task also has command-line programs (chat.js, sendOrder.js and exchange.js, person.js, tracker.js and query.js) that use the same RabbitMQ topics. See the README for how to run them.
